# Third-Party Data Notice

ThreatLens AI downloads pinned MITRE ATT&CK STIX 2.1 data from the official `mitre-attack/attack-stix-data` repository during setup or explicit synchronization.

Downloaded ATT&CK bundles are runtime data and are not committed to the ThreatLens source repository or included in immutable source releases. ThreatLens stores source URLs, collection IDs, release numbers, source-modified timestamps, and SHA-256 fingerprints for reproducibility.
