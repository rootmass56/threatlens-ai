# Project Objectives

1. To design and implement a SOC alert triage platform for security log analysis.
2. To parse and normalize logs from multiple sources such as Linux, Windows, Suricata, and Zeek.
3. To develop a rule-based detection engine for identifying suspicious security events.
4. To correlate related alerts into meaningful security incidents.
5. To map detections to MITRE ATT&CK tactics and techniques.
6. To generate incident timelines for analyst investigation.
7. To assign risk scores and severity levels to alerts and incidents.
8. To build a dashboard for visualizing alerts, incidents, risks, and attack timelines.
9. To implement a RAG-based assistant using ChromaDB and an LLM for grounded incident explanation.
10. To generate automated PDF incident reports with recommendations.
